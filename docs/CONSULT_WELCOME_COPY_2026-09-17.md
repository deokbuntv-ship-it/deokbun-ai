화면 구조 · 순서 · 버튼은 건드리지 않습니다.

## 지금 문구

```
안녕하세요. 덕분이입니다. 😊

출생정보 등록이 완료되었습니다.
상담을 시작할 준비가 되었습니다.

궁금한 점이나 고민이 있으시면 편하게 말씀해 주세요.
```

**무엇이 딱딱한가**
- "출생정보 등록이 완료되었습니다" · "상담을 시작할 준비가 되었습니다" 는 **시스템이 자기 상태를 보고하는 말**입니다. 사람에게 건네는 말이 아닙니다.
- 사용자가 다음에 무엇을 하면 되는지는 마지막 한 줄에만 있고, 그마저 "궁금한 점이나 고민" 이라 막연합니다.

## 지킨 톤 규칙 (세 안 모두)

- 과장하지 않습니다 (놀라운 · 정확한 · 꼭 맞는 ✗)
- 상담을 권하지 않습니다 (지금 바로 물어보세요 · 놓치지 마세요 ✗)

## 1안 — 조용한 환대 (가장 담백)

```
안녕하세요. 덕분이입니다. 😊

사주 정보는 잘 받았어요. 이제 편하게 이야기 나누시면 돼요.

마음에 걸리는 일이 있다면 그대로 적어 주세요. 딱 떨어지는 질문이 아니어도 괜찮아요.
```

- **달라지는 것:** 상태 보고("등록 완료 · 준비 완료")가 사람의 말("잘 받았어요")로 바뀝니다.
- **누구에게 맞나:** 말수가 적은 것을 좋아하는 사용자. 지금 톤에서 가장 적게 움직입니다.

## 2안 — 곁에 있는 사람 (가장 따뜻)

```
안녕하세요. 덕분이입니다. 😊

준비는 끝났어요. 무엇을 여쭤도 좋고, 아직 정리가 안 된 이야기여도 좋아요.

오늘 가장 마음이 가는 일부터 편하게 적어 주세요.
```

- **달라지는 것:** "정리가 안 된 이야기여도 좋다" 가 말문을 여는 문턱을 낮춥니다.
- **누구에게 맞나:** 무엇을 물어야 할지 몰라 첫 문장을 못 쓰는 사용자.

## 3안 — 질문을 돕는 (가장 실용)

```
안녕하세요. 덕분이입니다. 😊

사주 정보는 잘 받았어요. 이제 이야기만 시작하면 돼요.

"요즘 이직을 고민하고 있어요" 처럼, 지금 상황을 한 줄로 적어 주셔도 괜찮아요.
```

- **달라지는 것:** 예시 한 줄이 "어떻게 써야 하지" 를 없앱니다.
- **누구에게 맞나:** 첫 질문의 형식을 몰라 멈추는 사용자. 예시가 특정 주제(이직)로 쏠려 보일 수 있는 것이 대가입니다.

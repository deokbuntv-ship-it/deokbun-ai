## 2. 새 4종 — 양식에 어떻게 적는가

### 🆕 인앱 결제 기록

| 양식 칸 | 답 |
|---|---|
| 구글: 데이터 유형 | **금융 정보 → 구매 내역** |
| 애플: 데이터 유형 | **구매 항목 → 구매 내역** |
| 수집 목적 | 앱 기능(결제 검증), 사기 방지(중복 지급 차단) |
| 제3자 공유 | ⚠ **구글/애플이 결제 처리자**라 "공유" 가 아니라 "처리" 로 볼 여지가 있습니다 [법률 검토] |
| 사용자 계정과 연결 | **예** |
| 추적에 사용 | **아니요** |
| 삭제 | 탈퇴 시 원래 형태는 삭제 · **비식별 요약은 보존**(`account_deletions.purchase_record`, `user_ref = sha256(user_id)`) |

⚠ **구매 토큰(`purchase_token`)을 서버에 저장합니다** — 승인 재시도(3일 자동 환불 방지)에 필요하기
때문입니다. 토큰은 영수증 식별자이지 결제 수단 정보가 아닙니다. 카드 번호·계좌는 **받지 않습니다**
(스토어가 처리).

⚠ **확인 필요(CTO)**: 탈퇴 시 요약(`purge_account_data`)이 **테스트 구매 여부(`is_test`)를 담지 않습니다.**
매출 집계에서 테스트 구매를 거르려면 요약에도 그 칸이 필요합니다. 계정 삭제 계약(36건)을 건드리는
일이라 이번에 고치지 않았습니다.

### 4-3 처리방침과 대조 (`src/features/legal/legalContent.ts`)

| 항목 | 처리방침 | 이 초안 | 판정 |
|---|---|---|---|
| 상담 · 보고서 하나씩 삭제 | §5 · §6 에 경로와 범위가 있다 | 같음 | ✅ 맞음 |
| 답변 서버 사본 | §5 "답변 후 24시간 동안만 … 늦어도 25시간 안에 지워집니다" · 대화 삭제 시 즉시(연결 전 사본은 24시간 기준) | 같음 | ✅ 맞음 |
| 공유 검증 해시 | §5 "대화를 삭제한 뒤에도 … 탈퇴 시 함께 삭제" | 같음 | ✅ 맞음 |
| 오늘 · 이번 달 운세 | §5 `[법률 검토]` "보관 기간을 두지 않고 보관 · 탈퇴 시 삭제" | 같음 | ⚠ **[법률 검토]** — §5 첫 문단은 "이용자가 **삭제를 요청하면** 지체 없이 파기" 라고 적는다. 운세는 **탈퇴하지 않고 지울 방법이 없다**(항목별 삭제 기능 · 관리자 삭제 도구 모두 없음). 요청이 오면 처리할 경로를 정하거나, 문장을 운세에 맞게 고쳐야 한다 |
| OpenAI 로의 전송 | §3 은 OpenAI 를 **처리자(수탁자)** 로 적는다 | 표 §1 은 "제3자 전송처" 로 적었다 | ⚠ **[법률 검토]** — 구글 양식에서 서비스 제공자(수탁자)에게 넘기는 것은 "공유" 가 아닐 수 있다. 양식의 "공유" 답을 처리방침의 수탁 표현과 맞춰야 한다 |

⚠ 처리방침 **버전은 올리지 않았다** — CTO 판정(2026-09-14): 법률 검토를 반영할 때 한 번에 올린다.

#### 일간은 무엇으로 서 있나 — 통근

일간 정(丁)은 음화로, 화(火)로 섭니다. 통근(通根, 천간이 지지에 뿌리를 두는 것)은 일간과 시간 모두에 있습니다 (근거: 일간 정 통근 O — 년지 오·월지 오·시지 미, 시간 정 통근 O — 년지 오·월지 오·시지 미). 득령(得令, 계절의 힘을 얻은 상태)이어서 일간이 계절의 힘을 그대로 받는 상태입니다 (근거: 일간의 계절 단계 왕·득령, 월지 오·계절 여름). 참고로 이 글에서 쓰는 비겁·식상·재성·관성·인성은 각각 ‘일간과 같은 오행’, ‘일간이 생하는 것’, ‘일간이 극하는 것’, ‘일간을 극하는 것’, ‘일간을 생하는 것’이라는 뜻입니다 (근거: 무리의 뜻: 비겁 = 일간과 같은 오행 / 식상 = 일간이 생하는 것 / 재성 = 일간이 극하는 것 / 관성 = 일간을 극하는 것 / 인성 = 일간을 생하는 것).

#### 계절이 정하는 것 — 월령

월령(월지의 계절적 위치)은 오(午)로 여름의 기운이며, 이 때문에 일간이 득령(득령은 계절의 힘을 얻음) 상태에 있습니다 (근거: 월지 오·계절 여름·득령 표기). 자료의 생극 방향은 ‘계절과 일간이 같은 오행이므로 생극 없음’으로 명시되어 있습니다. 따라서 월령이 일간을 따로 생하거나 극하는 작동은 아닙니다 (근거: 월지 오·계절 여름, 생극 방향: 계절과 일간이 같은 오행 (생극 없음)). 월령의 힘이 강하게 작동하는 결과로 계절적 묶임이 형성되어 있습니다 (근거: 방합: 사·오·미 한 계절의 세 지지가 모인 관계).

#### 무엇이 많고 무엇이 없나 — 십성 분포

이 명식의 십성 분포는 비겁이 가장 많고, 식상이 그 다음이며 재성·관성·인성은 적은 편입니다 (근거: 십성 분포 비겁 7·식상 4·재성 2·관성 1·인성 1). 비겁(같은 오행인 비견·겁재)의 비중이 7로 두드러지므로 일간 주변에 같은 오행이 많은 형국입니다 (근거: 비겁 7). 일지 사(巳)의 지장간에는 무(상관)·경(정재)·병(겁재)이 있어 일지 쪽으로는 상관(식상 계열)이 가장 가깝게 드러나 있습니다 (근거: 일지 지장간 무(여기·상관)·경(중기·정재)·병(정기·겁재)). 눈에 띄게 부족한 것은 인성이 하나뿐이라는 점입니다 (근거: 십성 분포 인성 1).

#### 속에 있는 것과 드러난 것 — 지장간과 투간

지장간(地支 속에 숨은 천간들)과 투간(지장간이 천간으로 드러나는 것) 개념에서, 이 명식은 일부 지장간이 천간으로 이미 드러나고 일부는 여전히 숨겨져 있습니다 (근거: 투간 항목들 — 예: 년지 정·월지 정·시지 정이 일간·시간으로 투간됨, 그리고 숨은 채로 남은 지장간 목록 표기). 드러난 것과 숨은 것의 차이는 실제로 관측되는 십성의 분포에 영향을 줍니다. 예컨대 년지·월지의 정(정기 비견)이 투간되어 비겁 영향이 천간 수준에서 가시적입니다 (근거: 년지 지장간 정 → 일간·시간에 드러남·월지 지장간 정 → 일간·시간에 드러남, 십성 분포 비겁 7). 반대로 여러 지장간의 병·기·을·무 등은 아직 숨겨져 있어 겉으로 드러난 오행 수와 내부의 잠재성이 다르다는 사실을 보여 줍니다 (근거: 숨은 채로 남은 지장간 목록: 년지 병·기, 월지 병·기, 일지 무·병, 시지 을·기). 이 차이는 겉의 천간·지지 칸에서 세어지는 오행 개수와 지장간을 포함했을 때의 내부 구성이 다르다는 점으로 정리됩니다 (근거: 오행 개수는 겉으로 드러난 천간·지지 칸만 센 것이라는 명시).

#### 글자끼리 어떻게 맞물리나 — 합·충·형

5. `이 명식에서 갈리는 지점은 '천간이 뜬 경우'와 '지지에 통근하는 경우'의 차이입니다`

### (d) 관계 서술 — 새 항목

| | 언급 | 엔진 판정과 일치 | 엔진이 판정한 종수 |
|---|---:|---:|---:|
| ① 정 일간 | 4 | **4/4** | 6 |
| ② 계 일간 | 1 | **1/1** | 2 |
| ③ 기 일간 | 3 | **3/3** | 4 |
| **합** | **8** | **8/8 (100%)** | **12** |

**날조 0건.** 언급하지 않은 것은 있어도(같은 관계가 두 자리에서 중복 성립하는 경우를 한 번으로
묶어 씀), **없는 것을 만든 것은 하나도 없습니다.**

**부정 편향 검사** — 형·파·해를 나쁘게만 썼는가:

| 관계 | 본문이 실제로 쓴 말 |
|---|---|
| 해(害) | `두 지지가 서로의 합을 방해하는 자리입니다` — 사건이 아니라 구조 |
| 파(破) | `두 지지가 짜임을 흩는 자리입니다` — 중립 |
| 충(沖) | `묶임과 정면 충돌이 함께 존재합니다` — 반합과 나란히 놓았습니다 |
| 자형(自刑) | `같은 기운이 두터워지거나 안에서 맞물리는 구조입니다` — **양면** |
| 천간합(合) | `합은 묶임이므로 안정이거나 제 일이 묶여 정체되기도 합니다` — **양면** |
| 방합(方合) | `계절 기운의 두터움 또는 치우침을 나타냅니다` — **양면** |
| 육합(六合) | `결속 또는 정체의 구조를 이룹니다` — **양면** |

⚠ **"사고"·"다침"·"불행"·"흉" 같은 단어가 세 본문 어디에도 없습니다.** Premium V3 에서 합을
"얽힘"으로 자동 번역해 12개월이 전부 경고가 된 실패는 재현되지 않았습니다. 그리고 **합을
자동으로 긍정으로 쓰지도 않았습니다** — 넷 다 "이기도 하고 저렇기도" 형태입니다.

이것이 우연이 아닌 이유: **뜻 라벨 자체를 양면으로 적어서** 넘겼습니다. 라벨이 한쪽이면
모델이 그쪽으로만 씁니다 — 톤 제어는 프롬프트 훈계가 아니라 **입력 데이터에서** 시작합니다.
라벨 12개가 전부 양면인지는 테스트가 강제합니다(`famousRelations.test.ts`).

### (e) 문장 결함 — 7종 → 1종 (그리고 그 1종은 거짓 양성)

| v2 에서 나온 결함 | v3 |
|---|---|
| `지지의 지지(地支) 지지기반` (같은 말 3회) | **없음** |
| `숨아 있어` (오타) | **없음** |
| `(정의: 지장간과 투간 설명)` (빈 괄호) | **없음** |
| `외로움이 있어 보입니다` (근거 없는 감정어) | **없음** |
| `비견(같은 오행 임)와` (조사 어색) | **없음** |
| 세미콜론 (①에 4개, ③에 13개까지) | **0 — clamp 가 없앤다** |
| 문체 이탈 (`~로 본다.`) | **없음** |

기계가 잡은 것 1건: `같은 말 3회 연속: "일지 정·일지 을·일지"` (②)
→ ⚠ **거짓 양성입니다.** 원문은 `일지 미의 정·을·기` 를 열거한 정상 문장이고, 제 중복 검사가
열거를 반복으로 봤습니다. 경고 수준이라 발행을 막지는 않습니다.

**남은 진짜 결함** (기계가 못 잡고 사람이 읽어야 걸리는 것) — 전문 인용:

| 무엇 | 원문 | 어디 |
|---|---|---|
| 어색한 표기 | `겉에서 얼마나 단단히 섭(서) 있는지` | ① |
| ⚠ **투간 사실 오류** | `일지 미 지장간 정이 년간·월간으로 투간되어` — 이 명식의 년간은 갑, 월간은 병입니다. 정은 두 곳 어디에도 없습니다 | ② |
| 자기모순 문장 | `정과 을과 기 중 정만 천간으로 드러나 있지 않지만(정이 년·월간으로 투간되어 일간에 드러남)` — "드러나 있지 않지만 … 드러남" | ② |
| 군더더기 | `(글자 관계 풀이: 해·충·합 등은 관계의 이름이며 자료에 적힌 관계만 사용함)` — 프롬프트 지시를 본문에 옮겨 적었습니다 | ② |

②가 유독 나쁩니다. 셋 중 유일하게 **시각 미상(6칸)** 이라 근거가 적고, 근거 밀도도 69% 로 가장
낮습니다. 근거가 적을수록 모델이 빈칸을 메우려 한다는 신호로 읽힙니다.

### (f) 뜻 방향 오류 — **0건** (사람이 직접 확인)

| | 엔진 판정 | 본문이 쓴 것 | 판정 |
|---|---|---|---|
| ① | 왕(旺) = 같은 오행, 생극 없음 | `계절과 일간이 같은 오행이므로 생극 없음 … 월령이 일간을 따로 생하거나 극하는 작동은 아닙니다` | ✅ |
| ② | 왕(旺) = 같은 오행, 생극 없음 | `계절과 일간이 같은 오행이라 생극 관계가 발생하지 않습니다` | ✅ |
| ③ | 휴(休) = **일간이 계절을 생함** | `일간의 계절 단계는 휴(休)로서 '일간이 계절을 생함' 방향입니다` | ✅ |

v2 에서는 같은 종류의 오류가 **검사 없이 통과했습니다**(③의 `월령이 일간을 생해`).

## 5. 이번 트랙에서 바꾼 것

### 5-1. 검사기 — 차단에서 **대조**로

```
v1~v2:  본문에 "삼합" 이라는 단어가 있으면 거절
v3   :  본문이 "삼합(三合)" 을 주장하면
          → 엔진이 판정한 삼합 중, 참여 글자가 그 문장에 다 나오는 것이 있는가?
          → 없으면 거절
```

이쪽이 **더 강한 방어**입니다. 단어 차단은 진짜 관계와 지어낸 관계를 구별하지 못합니다.
대조는 구별합니다 — 그리고 **이름만 맞고 글자가 틀린 경우**까지 잡습니다.

오검출을 구조로 피했습니다: 관계 이름의 **한자가 앵커**입니다. `해석`·`파악`·`충분`·`종합` 은
한자를 달지 않으므로 애초에 후보가 되지 않습니다. (안전 라우팅에서 `세운`이 "세우다"와 겹쳐
배달된 답변 314건 중 2건을 버린 사건을 되풀이하지 않으려는 설계입니다.)

`INVENTED_RELATION` 정규식에는 **엔진이 끝내 판정하지 않는 것만** 남았습니다:
`원진 · 귀인 · 신살 · 공망 · 역마 · 도화 · 화개 · 형살 · 육파`.

### 5-2. 세미콜론 — 프롬프트로 세 번 실패, clamp 로 해결

| 시도 | 결과 |
|---|---|
| v2 프롬프트 금지 1회 | ③에 13개 |
| v3 프롬프트 금지 + 나쁜 예 | ①에 1개 |
| v3 거절 게이트 + 강한 문구 | ①에 4개, ③에 1개 |
| **결정론적 clamp** | **0** |

Premium 에서 *"프롬프트만으로는 LLM 이 슬쩍 되끼워넣는다"* 가 세 번 실증되고 결정론적 clamp 로
전환해 풀린 것과 **같은 곡선**입니다. 거절로 두면 LLM 콜만 계속 태웁니다.

⚠ 왜 치환이 안전한가: 한국어 산문에 세미콜론 관용이 없고, 실측 용례가 전부
`…입니다; 그다음…` 형태의 **독립 두 절**이라 마침표로 바꾸면 그대로 두 문장이 됩니다.

### 5-3. 검사기 자신의 거짓 양성 4건 (전부 정상 본문을 거절했다)

| 무엇 | 증상 | 수정 |
|---|---|---|
| `세운` 어휘 겹침 | *"일간을 중심으로 **세운** 판단은…"* 을 대운·세운으로 판정 | 레포의 기존 좁힘(앞 조사)에 **뒤 조사 조건**을 더했다 |
| 용어 **정의** 문장 | *"해(害)는 …를 뜻합니다"* 를 사례 주장으로 판정 | 참여 글자를 2개 이상 지목한 문장만 대조 |
| **가정법** | *"월령이 실령이면 읽는 방향이 달라"* 를 모순으로 판정 | `~면/경우/가정` 제외 |
| 열거 | `일지 정·일지 을·일지 기` 를 같은 말 3회로 판정 | ⚠ **미수정** — 경고 수준이라 남겼다 |

v2 트랙에서 5건, 이번에 4건. **검사기를 세게 만들수록 정상 본문을 거절할 위험이 함께 커집니다.**
그래서 실측 본문 9건(v1 3 · v2 3 · v3 3)을 회귀로 박아 두었습니다 — 거짓 양성의 유일한 방어선입니다.

## 6. 남은 문제 — 정직하게

### 6-1. ⚠ 투간 주장은 아직 대조하지 않습니다

②에서 `일지 미 지장간 정이 년간·월간으로 투간` 이라고 썼는데, **이 명식의 년간은 갑, 월간은
병입니다.** 엔진의 투간 판정은 `년지 계 → 일간`, `월지 계 → 일간` 뿐입니다.

관계 주장은 대조하는데 **투간·통근 주장은 대조하지 않습니다.** 같은 방식으로 확장할 수 있고
(스냅샷에 값이 다 있습니다), 이번 범위 밖이라 하지 않았습니다. **다음 지렛대로 남깁니다.**

### 6-2. 오타·조사는 여전히 기계가 못 잡습니다

`섭(서) 있는지` 같은 것은 사전 없이는 판정할 수 없습니다. 억지로 잡으려다 정상 문장을 거절하는
쪽이 더 나쁘므로 **못 잡는다고 못박고** 운영자 검토에 맡깁니다(테스트가 이 한계를 명시합니다).

### 6-3. 시각 미상 명식이 유독 약합니다

②는 근거 밀도 69%(다른 둘은 76·92%), 결함 3건 중 3건이 여기서 나왔습니다. 6칸이라 근거가 적고,
관계도 2종뿐입니다. **근거가 적을수록 모델이 빈칸을 메우려 합니다** — 근거량이 품질을 만든다는
Premium 의 관찰과 같은 방향입니다.

### 6-4. 원가가 또 올랐습니다

| | v1 | v2 | v3 |
|---|---:|---:|---:|
| input | 1,253 | 3,237 | **4,678** |
| output | 885 | 1,564 | **1,966** |
| **1명** | **2,138** | **4,801** | **6,644** |
| **100명** | 214k | 480k | **664k** |

v1 대비 **3.1배**입니다. 관계 12종 + 뜻 라벨이 input 을 1,441 토큰 늘렸습니다.

### 6-5. incomplete 는 발생하지 않았습니다

`max_output_tokens: 9000` 에서 최대 출력이 2,493 이었습니다(①). 여유가 큽니다.
⚠ 그래도 `status: 'incomplete'` 감지를 넣어 두었습니다 — 근거를 또 늘리면 닿을 수 있고,
잘린 JSON 은 파싱 실패로만 보여 원인을 못 찾습니다(요약 502 사건이 정확히 그랬습니다).

## 7. 교정 시간은 줄었는가

**줄었습니다. 1명당 5~10분 → 3~5분 정도로 봅니다.**

근거:
- 문장 결함이 7종 → 1종(그것도 거짓 양성). 세미콜론은 자동으로 사라집니다.
- 뜻 방향 오류가 기계에 잡힙니다 — v2 에서 사람이 읽어야만 걸리던 것입니다.
- 관계 날조가 기계에 잡힙니다.

**그런데 아직 "손대지 않고 발행" 은 아닙니다.** §6-1 의 투간 사실 오류처럼 **기계가 안 보는
영역의 사실 오류**가 남아 있고, 그것은 명리를 아는 사람이 읽어야 걸립니다.

그리고 품질과 무관하게 실존 인물 발행은 `OWNER_TODO` Z11 법률 검토 전에는 시작하지 말아 주십시오.

  |---|---|---|
  | `통근 O가 년·월·시·일에 나타남` | 월간 임은 통근 **X** | 통근 검사는 `(자리)간 + 글자` 짝을 요구한다. 자리만 나열하고 글자를 안 댔다 |
  | `일지의 정이 드러남` | 일지 정은 **투간되지 않았다** | 투간 검사는 `투간되/된/돼` 서술형을 요구한다. "드러남" 만 썼다 |
  | `일지 … 상관이 드러나 있습니다` | 무(상관)는 숨은 채 | 같은 이유 |
- **원인은 하나다**: 검사기가 **서술형 어휘**로 주장을 식별하는데 모델이 같은 사실을 **다른 말**로 쓴다.
  고치는 방향 둘 — ① 어휘를 넓힌다(오검출이 는다) ② **프롬프트가 자리+글자를 강제하게 한다**.
  ②가 낫다. 관계가 7/7 인 이유가 정확히 그것이다(참여 글자를 강제했다). 다음 지렛대.
- **✅ 2026-09-05 (v5) — ②를 했다. 위 세 오류가 사라졌다.** 프롬프트에 관계 절(③-2)과 같은 모양의
  전용 절(③-3)을 넣었다: 투간은 **(지지 자리 + 지장간 글자 + 천간 자리) 셋을 다 적고 `투간되었습니다`**
  로 쓸 것, 통근은 **`일간 정` 처럼 자리+글자를 붙여** 쓰고 자리만 나열하지 말 것.
  v4 의 세 오류 문장을 **나쁜 예로 그대로** 넣었다.
- **효과는 대조 건수에서 보인다**: 판정된 통근 주장이 **14건 → 33건(2.4배)**, 투간 4 → 7.

  늘어난 40건이 **전부 스냅샷과 일치**하고, 사람이 전수 대조해도 **사실 오류 0건**이다.
- **⚠ 그래도 남는 것 — 종류가 바뀌었다**: 기계 통과 뒤 사람이 2건을 찾았다.
  `일지 사의 여기인 무가 상관으로 들어 있어 일지의 주된 십성은 상관입니다` — 자리도 글자도 맞는데
  **여기(餘氣)를 주된 것이라 판정했다.** 스냅샷은 셋을 나열만 하고 등급을 매기지 않는다.

  나쁜 예로 넣었으나 **LLM 예산 30콜 소진으로 재생성 확인을 못 했다.**
- **⚠ 맞바꾼 것**: 근거 붙은 문장 비율이 **87% → 73%**. 자리+글자를 이미 말한 문장에 근거 괄호를

  하나도 없다.** 전부 "극성을 어느 구간에서 읽느냐" 였고 한국어 문법으로 구간을 정확히 했다:

### M-FAMOUS-2. 생성 본문의 **뜻 오류**는 기계가 잡지 못한다 (2026-09-04)

- **무엇**: v2 검사기는 **용어 이름이 뒤바뀐 경우**(득령↔실령, 왕↔휴)를 잡는다(`contradictsChart`).
  그런데 실측에서 **이름은 맞고 설명의 방향이 틀린** 문장이 나왔다:
  > `일간의 계절 단계는 휴(휴는 일간이 계절을 생함 — 내보내는 쪽)로 되어 있어 **월령이 일간을 생해**
  > 내보내는 역할을 합니다`

  앞 괄호는 옳다(휴 = 일간이 계절을 생함). 바로 뒤에서 방향을 뒤집어 한 문장 안에서 모순된다.
- **언제 터지는가**: 배우러 온 독자가 그 문장으로 개념을 거꾸로 익힐 때. 검색에 노출되는 교육
  콘텐츠라 틀린 설명이 인용되어 퍼질 수 있다.
- **왜 기계가 못 잡는가**: 문장의 주술 관계를 봐야 한다. 지금 검사기는 단어 수준이다. 여기에
  LLM 심판을 붙이면 원가가 2배가 되고 그 심판도 틀릴 수 있다.
- **✅ 2026-09-04 부분 해소 (v3)**: **생극 방향 자체를 기계가 대조한다**(`phaseDirectionErrors`).
  스냅샷에 방향을 별도 값(`direction`)으로 두고 본문의 "A이/가 … B을/를 생|극" 과 맞춘다.
  v3 실측에서 **실제로 1건을 잡았다**(계절 단계 왕인데 "계절이 일간을 생" 이라고 씀). 최종 3건은
  방향 오류 0이고, 사람이 직접 다시 읽어 확인했다.
  ⚠ **완전 해소는 아니다.** 문장 구조가 애매하면(주어·목적어가 분명하지 않으면) 판정하지 않는다 —
  오검출로 정상 본문을 버리는 쪽이 더 나쁘기 때문이다. 우회로가 남아 있다.
- **완화**: 본문은 **초안으로만** 돌아온다. 운영자가 [본문에 적용] 을 눌러야 들어가고, 그 전에
  화면에서 전문을 읽는다. **1명당 3~5분 교정을 전제로 운영한다**(v3 에서 5~10분에서 줄었다) —

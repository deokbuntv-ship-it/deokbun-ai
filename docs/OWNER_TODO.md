## ⚠ 개발자 계정 하나가 다섯 가지를 열어줍니다

이것이 지금 가장 중요한 사실입니다. **Apple Developer Program + Google Play Developer 계정**이
없으면 아래가 **전부** 막힙니다. 따로따로 미룰 수 있는 항목이 아니라 **하나의 선행 조건**입니다.

```
Apple Developer ($99/년) + Google Play ($25 1회)
        │
        ├─→ IAP 결제           — 상품 등록 · 샌드박스 계정 · 영수증 검증 (남은 최대 미완 항목)
        ├─→ 환불 처리          — 스토어 서버 알림이 있어야 환불이 원장에 들어옵니다
        ├─→ 애플 로그인 외부설정 — Service ID · .p8 키 (iOS 심사 필수)
        ├─→ Universal/App Link — Team ID · 앱 서명 SHA-256 (앱 유입 추적의 전제)
        └─→ 스토어 심사 제출    — 애초에 계정이 있어야 제출이 됩니다
```

**계정 등록 자체는 1시간이고 승인에 며칠 걸립니다.** 그래서 다른 무엇보다 먼저입니다.

  실측으로 확인했습니다 — 일반 상담·궁합·Premium **셋 다** 같은 조건에서 실패합니다.

### A3. 앱 유입 추적 개통 — 4단계

지금은 **폰에서 광고 링크를 눌러도 앱이 아니라 브라우저가 열립니다.** 앱 유입이 0으로 잡힙니다.

1. **Team ID 복사** — Apple Developer → **Membership** → Team ID (10자리)
   → `public/.well-known/apple-app-site-association` 의 `REPLACE_TEAM_ID` 교체
2. **SHA-256 지문 복사** — Google Play Console → **설정 → 앱 서명 → SHA-256 인증서 지문**
   → `public/.well-known/assetlinks.json` 의 `REPLACE_SHA256_FINGERPRINT` 교체 (콜론 포함 형식 그대로)
3. **`app.json` 반영** — diff 는 `PROJECT_STATE.md` §8.5. **애플 로그인 diff 와 같은 파일이니 한 번에**
4. **EAS 재빌드 + 웹 재배포**

- **계정·비용**: B1 의 두 계정
- **시간**: 30분 + 빌드 시간
- **열어주는 것**: 앱 유입 추적, 링크가 앱에서 바로 열림
- **선행**: **B1**
- **⚠ 배포 후 애플 CDN 반영에 최대 24시간** 걸립니다. 바로 안 된다고 잘못된 게 아닙니다
- 상세: `PROJECT_STATE.md` §7.12-A · §7.14

살아 있는가" 를 본 것이고, **네이버 버튼 → 동의 → 로그인 성공까지는 production 에서 눌러 보셔야
합니다.** (`NAVER_LOGIN_ARCHITECTURE.md` §7 기록으로는 2026-08-12 에 이미 한 번 성공했습니다.)

남은 확인 하나 — **`EXPO_PUBLIC_NAVER_CLIENT_ID` 가 Vercel 환경변수에 있는지**는 제가 코드로
확인할 수 없습니다. 없으면 앱이 네이버 인증 창을 아예 열지 못하고 `OAUTH_URL_MISSING` 으로 끝납니다
(Edge 까지 가지도 않으니 500 조차 안 뜹니다). Vercel → Settings → Environment Variables 에서
이름이 있는지만 봐 주십시오.

#### ③ 발행하면 자동으로 다시 만들기 (Deploy Hook)

**Vercel → Settings → Git → Deploy Hooks**

1. **Hook Name**: `publish-rebuild` (아무 이름이나 괜찮습니다)
2. **Git Branch Name**: 배포에 쓰는 브랜치 (보통 `main`)
3. **Create Hook** → 만들어진 **URL 을 복사**합니다
   (`https://api.vercel.com/v1/integrations/deploy/...` 형태)

⚠ **이 URL 은 비밀번호와 같습니다.** 가진 사람은 누구나 배포를 무한히 돌릴 수 있으니
카카오톡·메모장에 남기지 마시고, 아래에 넣은 뒤 지워 주세요.

4. 개발 쪽에 전달해 주시거나, 직접 넣으시려면
   **Supabase → 프로젝트 → Edge Functions → Secrets → Add new secret**

| Name | Value |
|---|---|
| `VERCEL_DEPLOY_HOOK_URL` | 복사한 URL |

#### 넣고 나면 어떻게 되나

발행 버튼을 누르시면:

1. 내용이 **즉시** 저장되고 앱에서는 바로 보입니다
2. 사이트 재생성이 자동으로 요청됩니다 (사람 손 없음)
3. 화면에 **"사이트 재생성을 요청했습니다. 보통 2~5분 뒤 검색용 페이지에 반영됩니다"** 가 뜹니다
4. 그 아래 **"마지막 사이트 재생성 요청: N분 전"** 이 계속 남아 있어서, 다시 들어와도 확인됩니다

- 연달아 여러 명을 발행하셔도 **빌드는 한 번만** 돕니다(3분 안의 요청은 합쳐집니다).
  나중에 시작한 빌드가 그 사이 저장한 내용을 전부 담습니다.
- 진행 상황을 직접 보고 싶으시면 **Vercel → Deployments** 에서 확인하실 수 있습니다.

- **계정·비용**: 없음 (기존 Vercel·Supabase 안에서)
- **시간**: 15분
- **선행**: 도메인 `deokbunai.com` 이 Vercel 에 연결돼 있어야 합니다

# V1.1 REUNION PROFESSIONAL REPORT — BOUNDARY (§X)

> **Status:** ROADMAP / BOUNDARY ONLY (Sprint F). **Not implemented in V1.** This file exists to reserve the
> product and fix its safety boundary so no one accidentally builds it as a renamed compatibility flow.

## 1. What it is (and is not)

**재회 전문 리포트 (Reunion Professional Report)** is a **separate V1.1 product**, not a rename or reskin of the
V1 궁합 (compatibility) flow. It is a distinct, higher-priced narrative report about a relationship's structure
and trajectory, aimed at users navigating a breakup / estrangement.

## 2. Allowed scope (candidate content)

- 관계 구조 — the relationship's structural dynamics.
- 현재 갈등 / 단절 상태 — the present conflict / disconnection state.
- 반복 패턴 — recurring patterns.
- 시기별 관계 흐름 — the relationship's flow across periods.
- 재접촉 / 대화에 상대적으로 유리하거나 불리한 구간 — periods **relatively** more/less favorable for
  re-contact or conversation (framed as tendencies, never guarantees).
- 사용자가 통제 가능한 현실적 대응 — realistic actions **the user** can control.

## 3. Forbidden (hard safety boundary — inherits V1 policy)

- ❌ "상대가 반드시 돌아온다" — asserting the other person will certainly return.
- ❌ "몇 월에 반드시 연락한다" — asserting a certain month of contact.
- ❌ 상대방의 의사 / 행동을 단정 — asserting the other person's will or behavior as fact.
- All existing guards apply: no event-certainty, no other-person mind-reading, no winner/ranking, crisis
  hard-stop precedes everything. The compatibility euphemistic-breakup guard also applies.

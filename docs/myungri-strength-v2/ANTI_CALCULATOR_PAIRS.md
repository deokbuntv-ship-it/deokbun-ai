# ANTI-CALCULATOR PAIRS — S1.5

Status: **S1.5 RESEARCH ARTIFACT — NOT CANONICAL DOCTRINE**

## What this file is for

Not to assert that counting fails. To **demonstrate** it, on charts, with the
source's own reasoning quoted — so that a future V2 axis can be tested against
cases that a count-based model provably gets wrong.

A pair qualifies when two charts are **close on any naive tally** (element
counts, support-vs-opposition, month command, root presence) yet the authority
reaches **materially different conclusions**, and states a structural reason.

Every pair below is from SRC-001 (滴天髓闡微, 任鐵樵). **Cross-lineage pairs are the
S1.5 gap** — see the closing section.

**16 pairs. 13 are the author's own deliberate constructions** — he says so, in
phrases like 與前只換一寅字, 故特書兩造為後證, 觀格局似勝前造, 大象觀之勝於前造.
That matters: these are not pairs I assembled by hunting for anomalies. They are
controlled comparisons built by the source to defeat mechanical reading.

## AC-01 — 失令 outperforms 得令 + 通根 + 身旺

| | Chart A `DTS-YUELING-01` | Chart B `DTS-YUELING-02` |
|---|---|---|
| Chart | 甲戌 丙寅 戊寅 丙辰 | 甲戌 丙寅 戊辰 庚申 |
| Naive read | 煞旺身弱 — every indicator negative | 得令 + 通根 + 身旺 — every indicator positive |
| Outcome | 名利雙收 | 書香難遂，一生起倒不寧 |

**COUNT_SIMILARITY:** identical year and month pillars; same Day Master element;
B additionally has month command, a root, and is called 身旺. On any tally B
outranks A.

**STRUCTURAL_DIFFERENCE:** A has 貼身透丙 (Fire adjacent to the Day Master,
converting 殺 into support). B's Fire is present but the chart is 嫩木寒土 needing
Fire, and B's 庚申 drains instead.

**JUDGMENT_DIFFERENCE:** complete inversion of outcome.

**SOURCE_REASONING:** A — 似乎煞旺身弱。然喜無金…尤羨貼身透丙，化殺生身. B —
**俗論**比之，勝於前造，**不知**嫩木寒土皆喜火.

The author names the conventional reading and rejects it, in both directions.

## AC-02 — 旺極 and 弱極 both invert their treatment

| | Chart A `DTS-TIYONG-01` | Chart B `DTS-TIYONG-02` |
|---|---|---|
| Chart | 丙寅 甲午 丙午 癸巳 | 戊寅 庚申 丙申 丙申 |
| Label | 旺之極矣 | 弱極 |
| Treatment | 從其強勢 | 從其弱勢 |

**COUNT_SIMILARITY:** opposite extremes, so not a count-similarity pair — this is
the *symmetry* pair, included because the author explicitly built it as one.

**STRUCTURAL_DIFFERENCE:** A is maximally self-supported; B has a root that is
**拔** (uprooted by 二申沖去一寅) and 比肩 that are **不能為力**.

**JUDGMENT_DIFFERENCE:** in both, the naive treatment (抑 the strong, 扶 the weak)
is explicitly harmful.

**SOURCE_REASONING:** A — 旺極者，抑之反激而有害也. B — 弱極者扶之，徒勞無功，反有害也.
And: **故特書兩造為後證** — "I therefore record two charts as later proof."

**Why it matters:** presence of 比肩 is not function of 比肩. B has them and they
are 不能為力. A count sees them; the source does not credit them.

## AC-03 — One character in the hour pillar inverts the outcome

| | Chart A `DTS-BAGE-04` | Chart B `DTS-BAGE-05` |
|---|---|---|
| Chart | 辛卯 丙申 癸卯 **壬戌** | 辛卯 丙申 癸卯 **甲寅** |
| Luck | identical | identical |
| Outcome | 名利兩全 | 機杼空拋，守株待兔 |

**COUNT_SIMILARITY:** three of four pillars identical; same luck cycle. Any
feature vector differs in one slot.

**STRUCTURAL_DIFFERENCE:** A's 壬 is the 藥 (remedy) for the 病 (丙火). B's 甲寅
**generates the disease** — 生助病神 — and 寅申遙沖 damages the 印.

**JUDGMENT_DIFFERENCE:** full career vs none. No strength band moves.

**SOURCE_REASONING:** 與前只換一寅字，不但有病無藥，而且生助病神.

**Why it matters:** the operative model here is 病/藥 (disease/remedy), which is
**not a strength axis at all**. A strength-only engine has no representation for
the difference between these two charts.

## AC-04 — Same clash, opposite verdicts on the rule 墓庫逢沖必發

| | Chart A `DTS-BAGE-08` | Chart B `DTS-BAGE-09` |
|---|---|---|
| Chart | 丁未 癸丑 甲辰 甲戌 | 丁亥 癸丑 甲子 辛未 |
| Luck | identical | identical |
| Outcome | 家業破盡，無子而亡 | 早遊泮水，戰勝秋闈 |

**COUNT_SIMILARITY:** same Day Master, same month, same year stem, same luck.

**STRUCTURAL_DIFFERENCE:** in A the 丑未沖 **fires** (adjacent), destroying 庫根 and
leaving only a 微根. In B 丑未遙隔 and 水勢乘權 so the clash **cannot fire**.

**JUDGMENT_DIFFERENCE:** 財多身弱, ruin — vs 中和之象, success.

**SOURCE_REASONING:** 前則逢沖，官印兩傷…此則不動，名成利遂。**可知墓庫逢沖必發者，謬也。**

**Why it matters:** the difference is whether a relation *activates*, which
depends on adjacency. Position is not a count.

## AC-05 — The author's own chart, one branch different

| | Chart A `DTS-GUANSHA-12` | Chart B `DTS-GUANSHA-13` (任鐵樵's own) |
|---|---|---|
| Chart | **癸丑** 戊午 丙午 壬辰 | **癸巳** 戊午 丙午 壬辰 |
| Outcome | 名利裕如，履黄堂 | 半生事業，亦似浮雲 |

**COUNT_SIMILARITY:** identical but for the year branch. Same Day Master, month,
hour; both 火長夏天, both 旺之極矣.

**STRUCTURAL_DIFFERENCE:** 丑 is 北方濕土 — it 晦火, 收午火之焰, 蓄水藏金, so 戊癸合
**does not** transform. 巳 is 南方之火 — 癸臨絕地, so 戊癸合 **must** transform, into
Fire, which becomes 劫 and feeds the 陽刃.

**JUDGMENT_DIFFERENCE:** the same combination (戊癸) transforms in one and not the
other, reversing its meaning from helper to enemy.

**SOURCE_REASONING:** 與前造只換一丑字，**天淵之隔**矣 … 彼則戊癸合而不化，此則戊癸合而
必化，不但不能助殺，抑且化火為劫.

**Why it matters:** whether a combination transforms is decided by the *environment
of the participants*, not by their presence. This is the highest-confidence pair in
the corpus — the author had every reason to get his own chart right.

## AC-06 — "Looks better, fares worse"

| | Chart A `DTS-GUANSHA-03` | Chart B `DTS-GUANSHA-04` |
|---|---|---|
| Chart | 戊子 甲寅 戊午 甲寅 | 己亥 丙寅 戊子 甲寅 |
| Naive read | 土衰木盛 | 財印坐長生 — better on paper |
| Outcome | 早登黃甲，出仕馳名 | needed two specific years to pass |

**COUNT_SIMILARITY:** same Day Master element, same month branch, both 殺重.

**STRUCTURAL_DIFFERENCE:** what sits **under** the Day Master. A: 坐下午火 (印),
so 七殺皆來生拱 and 日主堅固. B: 財坐日下, so the 財 **generates the 殺** — 助紂為虐.

**JUDGMENT_DIFFERENCE:** the same elements in different positions reverse role.

**SOURCE_REASONING:** 觀格局**似勝**前造 … **不知** 前則坐下印綬…而日主堅固，此則財坐日下，
反去生殺.

**Why it matters:** 眾殺橫行，一仁可化 (from A) — many adversaries neutralised by one
correctly-placed resource. Explicit refutation of headcount, in the source's words.

## AC-07 — Both weak, opposite correct remedies

| | Chart A `DTS-XINGXIANG-19` | Chart B `DTS-XINGXIANG-20` |

**COUNT_SIMILARITY:** same Day Master stem (丙), both labelled weak.

**Why it matters:** this is the pair that shows a *correctly sourced* strength band
would still be operationally insufficient. See `TASK_RELATIVE_JUDGMENT_ANALYSIS.md`

## AC-08 — Both prosperous, opposite correct remedies

| | Chart A `DTS-XINGXIANG-17` | Chart B `DTS-XINGXIANG-18` |
|---|---|---|
| Chart | 丁丑 庚戌 庚子 甲申 | 戊申 壬戌 庚申 乙酉 |
| Correct remedy | **傷**之有功 (官殺) | **洩**之有益，**傷**之有害 (食傷) |

**STRUCTURAL_DIFFERENCE:** A has 官星虛脫 — the officer needs strengthening, so

**SOURCE_REASONING:** 均是旺也，或洩之有害，而傷之有利；或洩之有利，而傷之有害.

**Why it matters:** the mirror of AC-07 on the prosperous side. Four operations
(幫/助/洩/傷), and the label selects none of them.

## AC-09 — Both 旺之極矣, different remedy element

| | Chart A `DTS-GANGROU-01` | Chart B `DTS-GANGROU-02` |
|---|---|---|
| Chart | 壬申 戊申 庚辰 甲申 | 壬戌 戊申 庚寅 丙戌 |
| Label | 旺之極矣 | 旺之極矣 |
| Remedy | 壬水 (洩) | 丙火 (制) |

**COUNT_SIMILARITY:** same Day Master, same month pillar, same year stem, same
label, overlapping luck cycles.

**STRUCTURAL_DIFFERENCE:** A's 壬水 is usable (year stem, 地支三申 feeding it).
B's 壬水 is 坐戌逢戊 — 梟神奪盡 — so the outlet is destroyed and 丙火 must be used

**Why it matters:** identical labels, and the remedy is chosen by which candidate
element **survives**, not by the label.

## AC-10 — Same composition, one is 從強 and one is not

| | Chart A `DTS-FANGJU-03` | Chart B `DTS-FANGJU-04` |
|---|---|---|
| Chart | 甲寅 乙亥 乙卯 癸未 | 甲寅 丁卯 乙未 丁亥 |
| Composition | 木局全，混一寅字 | 木局全，混一寅字 |
| Verdict | 其勢**從強** | **非**前造從強論也 |

**COUNT_SIMILARITY:** the source itself describes both with the *same phrase*.
Both are Wood Day Masters with a complete Wood 局 plus an extra 寅.

**STRUCTURAL_DIFFERENCE:** B has 丁火食神 — a usable outlet. A has 四柱無金 and no
functional outlet, so the force has nowhere to go but forward.

**JUDGMENT_DIFFERENCE:** special-pattern membership differs on identical
composition. Luck preferences then diverge: A likes 東南北, B is harmed by 西北.

**SOURCE_REASONING:** 取丁火食神秀氣，**非前造從強論也** … 前則從強，南北皆利；此則木火，
西北有害.

**Why it matters:** **composition does not determine the pattern; the presence of a
functional outlet does.** This is the single most important pair for special-pattern
work, and it is why a composition-threshold model of 從格 cannot work.

## AC-11 — An explicit count, stated and then overturned

| | Chart A `DTS-FANGJU-09` | Chart B `DTS-FANGJU-10` |
|---|---|---|
| Chart | 辛未 辛卯 乙未 **丁亥** | 辛未 辛卯 乙未 **戊寅** |
| Luck | identical | identical |

**COUNT_SIMILARITY:** three pillars identical. B's own text performs the tally:
**局中三土兩金** — three Earth, two Metal against the Day Master.

**STRUCTURAL_DIFFERENCE:** 卯旺提綱 and 支中皆木之根旺. The Metal has no 得地.

**JUDGMENT_DIFFERENCE:** the count says 財生煞旺 (Day Master under pressure); the
source says the opposite.

**SOURCE_REASONING:** 以大象觀之，局中三土兩金，**似乎**財生煞旺，**不知**卯旺提綱，
支中皆木之根旺，非金之在地也.

And A's own line: **此所謂強眾而敵寡，勢在去其寡，非煞旺宜制而推也** — treatment
derived from the 眾/寡 *relation*, explicitly **not** from the adversary's strength.

**Why it matters:** this is the corpus's cleanest instance of a count being
*stated* and then *subordinated*. 眾 and 強 appear as independent modifiers of one
party (強眾), which is the same finding as 強寡 in 眾寡第三十三.

## AC-12 — A truer transformation fares worse

| | Chart A `DTS-HUAXIANG-03` | Chart B `DTS-HUAXIANG-04` |
|---|---|---|
| Chart | 己卯 丁卯 壬午 **甲辰** | 己卯 丁卯 壬午 **癸卯** |
| Transformation | 化象斯真 | 化象**更**真，化神**更**有餘 |
| Outcome | 少年科甲，翰苑名高 | 雖中鄉榜，終不能出仕 |

**STRUCTURAL_DIFFERENCE:** B's 癸 is a 劫 that competes for the 財 — 癸劫爭財 — and

**Why it matters:** the quality metric moves **up** and the outcome moves **down**.
Any monotonic model of "pattern purity ⇒ better result" fails here.

## AC-14 — Peers rooted vs peers unrooted, same pattern

| | Chart A `DTS-SHUNJU-05` | Chart B `DTS-SHUNJU-09` |
|---|---|---|
| Chart | 甲午 丁丑 甲午 丙寅 | 壬子 辛亥 辛卯 辛卯 |
| Peers | 逢**祿比**幫身 (rooted) | **三透辛金**，地支**臨絕** (unrooted) |
| Verdict | 格取從兒 | 格取從兒 |

**COUNT_SIMILARITY:** B has *more* peer stems (three) than A. A naive peer-count
would call B the stronger Day Master.

**STRUCTURAL_DIFFERENCE:** A's peers are rooted, B's are not — and the pattern
holds either way.

**SOURCE_REASONING:** A — 所謂**從兒不論身強弱，非身弱論也**.

**Why it matters:** the source separates stem-presence from branch-rooting, and
then declines to make either decide the pattern. This pair is the empirical core
of CF-004/CF-008.

## AC-15 — Season reversed in both directions

| | Chart A `DTS-GUANSHA-01` | Chart B `DTS-GUANSHA-14` |
|---|---|---|
| Chart | 己酉 丙寅 庚申 庚辰 | 戊申 癸亥 丙午 壬辰 |
| Season says | 春金失令 → weak | 坐旺刃 → strong |
| Source says | **弱中變旺** | 雖坐旺刃，**究竟休囚** |

**STRUCTURAL_DIFFERENCE:** A gains 兩逢祿旺 + 印比幫身 against the season. B's 刃 is
overridden by 生於亥月 plus 壬癸並透各立門戶.

**SOURCE_REASONING:** A — 以俗論之，春金失令…**不知**春金雖不當令，地支兩逢祿旺…弱中變旺.

input among several, and the corpus contains reversals in **both** directions.
Any model treating 月令 as a weight or a gate fails one of these two.

## AC-16 — Extreme composition, special pattern refused

| | Chart `DTS-BAGE-06` |
|---|---|
| Chart | 己巳 庚午 丙午 甲午 |
| Naive read | 支全三午, 四柱滴水全無, no water luck → 飛天祿馬 special pattern |
| Source | 真火土傷官生財格 — an **ordinary** structure |

**COUNT_SIMILARITY:** maximal — this is as compositionally extreme as a chart gets.
This is a **singleton**, included because it is the negative control the others
lack.

**SOURCE_REASONING:** 此造俗論…必作飛天祿馬…**不知**此造午中己土，巳中庚金，元神透出
年月兩干，真火土傷官生財格.

**Why it matters:** extremity of composition does **not** license a special
pattern. Combined with AC-10, the picture is consistent: special-pattern
membership turns on **whether a functional outlet exists**, not on how extreme the
composition looks.

## What these pairs collectively establish

Not "counts are bad" — something more specific and more useful:

1. **Position is not a count.** AC-03, AC-04, AC-06, AC-13 all turn on *where* an
   element sits (adjacent vs remote, under the Day Master vs elsewhere, hidden vs
   exposed).
2. **Presence is not function.** AC-02 (比肩 不能為力), AC-09 (壬水 梟神奪盡),
   AC-11 (金 非在地) — elements that a tally sees and the source does not credit.
3. **Relations activate conditionally.** AC-04 (沖 fires only when adjacent),
   AC-05 (合 transforms only in the right environment).
4. **Quality is not monotone in the naive metric.** AC-12 (truer 化, worse life),
   AC-13 (better 大象, worse life).
5. **The label does not select the treatment.** AC-07, AC-08, AC-09 — four
   distinct operations, none determined by the band.
6. **Special-pattern membership turns on outlets, not composition.** AC-10, AC-16.

A V2 axis proposal should be testable against these sixteen. An axis that cannot
distinguish the members of any pair is not measuring what the source measures.

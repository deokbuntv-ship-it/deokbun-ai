# DOCTRINE OBSERVATIONS — S1

> **These are observations, not rules.** S1 collects; S2 decides. A pattern seen in three cases is three
> cases. Nothing here has `RULE_CANDIDATE` status, and per §44 of the governing plan no rule may be
> declared during early extraction.
>
> Every observation carries supporting **and** contradicting case ids, source diversity, and an honest
> confidence. Where the corpus is single-source, that is stated — because a single lineage's habits look
> exactly like universal doctrine until you check.

## OBS-01 — The source is *itself* adversarial against formulaic strength rules

| Field | Value |
|---|---|
| **Observation** | 任鐵樵 repeatedly constructs examples specifically to defeat mechanical readings, and says so in his own voice: 似乎…然 ("it would appear… however"), 俗論…不知 ("the conventional reading… fails to grasp"), 故特書兩造為後證 ("I therefore record two charts as later proof"), 此種謬論，必宜一切掃除也 ("such fallacies must be swept away entirely"). |
| **Supporting cases** | `DTS-YUELING-01/02` (似乎煞旺身弱 · 俗論…勝於前造，不知) · `DTS-TIYONG-01/02` (故特書兩造為後證) · `DTS-CONGXIANG-01` (似乎財多身弱，但…其勢必從) · `DTS-ZHONGHE-02` (似乎旺相，不知財殺太重) · `DTS-BAGE-06` (此造俗論…不知) · `DTS-BAGE-09` (可知墓庫逢沖必發者，謬也) |

| **Confidence** | **HIGH** for the observation; its *generalization* to other lineages is untested |
| **Why it matters** | V1 spent four revisions trying to extract a formula from a text whose author's stated purpose is to refute formulas. Any V2 axis must be able to reproduce these inversions, or it has learned the opposite of what the source teaches. |
| `READY_FOR_RULE?` | **NO** — this is a methodological finding, not a rule |

## OBS-02 — 眾/寡 (numerousness) and 強/弱 (strength) are **independent axes** in the source

| Field | Value |
|---|---|
| **Observation** | The 眾寡 chapter uses the compound **強寡** — "strong but few" — which is only coherent if count and strength are separate dimensions. It further states that a scarce force *with backing* becomes strong: 「官星雖寡，得財星扶則強」. |
| **Supporting cases** | `DTS-ZHONGGUA-03` (日主本不及時，第坐陽刃會火局，謂之**強寡**) · `DTS-ZHONGGUA-01` (乙木無根，傷官又旺，其勢足以**敵官星之寡**) · `DTS-FANGJU-09` (此所謂**強眾而敵寡**，勢在去其寡) · `DTS-FANGJU-08` (必須**棄其寡而從其眾**也) · 眾寡 任氏曰 (「此日主之黨眾，敵官星之寡」) |
| **Contradicting** | none found |
| **Source diversity** | single-source (SRC-001), but across three separate chapters |
| **Confidence** | **HIGH** |
| **Why it matters** | This is the most consequential S1 finding so far. V1.3 modelled 黨眾/助寡 as an equal-weight occurrence count and let it choose a strength family; the audit rejected that as unfaithful. The corpus now shows *why* it was unfaithful: the source treats 眾/寡 as a **separate axis** from 強/弱, and explicitly allows 強寡 (few-but-strong) and 寡…得扶則強 (few-but-backed-therefore-strong). A count cannot be the strength verdict because in this source it is not even the same question. |
| `READY_FOR_RULE?` | **NO** — but it decisively rules *out* an entire family of candidate rules (R10) |

## OBS-03 — Root outranks visible stems, in **bounded** comparatives

| Field | Value |
|---|---|
| **Observation** | 衰旺's 任氏曰 states a comparative ladder in the source's own words: 「天干得一比肩，不如地支得一餘氣墓庫…得二比肩，不如支中得一長生祿旺…蓋比肩如朋友之相扶，通根如家室之可托，**干多不如根重**」. It also grades roots: 「長生祿旺，根之重者也；墓庫餘氣，根之輕者也」. |
| **Supporting cases** | 衰旺 任氏曰 (the passage itself) · `DTS-TIYONG-02` (比肩亦不能為力 — visible 比肩 present and explicitly powerless once the root is 拔) |
| **Contradicting** | none found yet |
| **Source diversity** | single-source (SRC-001) |
| **Confidence** | **MEDIUM-HIGH** for the comparatives as stated; **LOW** for any generalization |
| **Critical caution** | These are **bounded** comparatives — one 比肩 < one 餘氣/墓庫 root; two 比肩 < one 長生/祿旺 root. They are **not** a licence for "any root outranks any number of stems", and they are **not** weights. V1 was warned about exactly this over-generalization and it remains the tempting error here. |
| `READY_FOR_RULE?` | **NO** — needs cases where the comparative is actually applied to decide a chart |

## OBS-09 — Explicit strength vocabulary is **rarer** than expected

| Field | Value |
|---|---|
| **Observation** | Across the 衰旺/中和/眾寡 block (25 charts), **none** contains the literal strings 身弱, 身旺, 財多身弱, 從財, 從殺, 任財, or 不任財官. That chapter reasons in a different register entirely: 太旺/旺極/太衰/衰極 + 「似X」 reversal. Across the 形象/方局/八格 block (40 charts), bare 身弱 appears **zero** times; 財多身弱 appears twice; 身旺 once. |
| **Supporting cases** | full-text scans of both blocks |
| **Confidence** | **HIGH** |
| **Why it matters, and it is a warning** | A corpus built by searching for 身強/身弱 would have **missed most of this material**, and would have over-sampled the minority of charts that happen to use product-shaped vocabulary. The source's real strength reasoning is conducted in structural language (通根, 無根, 根重, 拔, 秉令, 當權, 乘旺, 洩, 剋, 從其X勢), not in labels. V2's normalized label vocabulary must map from *that* register, and `SOURCE_NOT_EXPLICIT` will be a common and correct answer |
| `READY_FOR_RULE?` | n/a — a corpus-design finding, and it partly vindicates keeping the S1 label vocabulary conservative |

## OBS-11 — 足以 is task-relative in **every** occurrence, without exception

| Field | Value |
|---|---|
| **Observation** | 足以 appears **18 times across 17 records**. In not one instance is it a global property of the Day Master. It always takes (a) a **named load** and (b) a **named structural ground**: 足以敵官 · 足以敵官擋殺 · 足以制殺 · 足以用財 · 足以用官 · 足以用辛金制殺 · 足以盤根制殺 · 足以止水托根 · 足以砥定汪洋 · 足以砥定中流 · 足以晦火養金 · 足以補日主之虛 · 足以任其財官 · 足以扶身敵殺. The negated form matches: 未足幫身, 本不足疏土, 不足畏也. |
| **Supporting cases** | `DTS-GUANSHA-10/11/21/24` · `DTS-GANGROU-03` · `DTS-FANJU-01/02/08/13/17` · `DTS-SHANGGUAN-03/06/13/19` · `DTS-XINGXIANG-17` · `DTS-FANGJU-01` |
| **Contradicting** | none found |
| **Three sub-findings, each independently fatal to a global predicate** | ① It is twice predicated of an **adversary** (財星足以破印, `DTS-FANJU-17`) — the construction measures adequacy-to-task for any party, favourable or not. ② It is once scoped to a **luck period**, not the natal chart: 甲子癸亥，印旺逢生，日元足以任其財官 (`DTS-FANJU-13`). ③ It coexists with **extreme weakness** in one chart: 日元虛脫極矣 … 足以用辛金制殺 (`DTS-FANJU-08`). |
| **Confidence** | **HIGH** — 18 occurrences, 8 chapters, zero counterexamples |
| **Why it matters** | This is the empirical basis for the V1 closure. `CAN_BEAR` / `CANNOT_BEAR` as global natal predicates have **no support anywhere in the corpus**. The source never asks "can this Day Master bear?" — it asks "is *this element* adequate to *this task*, given *this structure*, in *this period*?" Sub-finding ③ additionally shows that weakness and capacity are not on one scale: a chart can be maximally depleted and still adequate to a specific job. |
| `READY_FOR_RULE?` | **NO** — but it is a hard **constraint on any future rule**: a V2 capacity claim must name its load, its ground, and its temporal scope, or it is not saying what the source says |

## OBS-12 — One chart can carry two incompatible classifications by the same author

| Field | Value |
|---|---|
| **Observation** | Two charts appear in two chapters each, read differently both times by 任鐵樵. 癸卯 乙卯 甲寅 乙亥 is 木旺極者似火 in 衰旺 and 從其旺神 in 從象. 庚申 乙酉 庚戌 庚辰 is 金旺極者似水 in 衰旺 and 格成從革 in 形象 — two readings with **no shared vocabulary at all**. |
| **Supporting cases** | `DTS-SHUAIWANG-02` / `DTS-CONGXIANG-06` (CF-001) · `DTS-SHUAIWANG-14` / `DTS-XINGXIANG-13` (CF-009) |
| **Contradicting** | none — but note the sample is only the 2 charts that happen to be reprinted |
| **Confidence** | **MEDIUM-HIGH** — the observation is certain for these charts; whether it generalises is not established |
| **Why it matters, and this is the deepest finding of S1** | The classification a chart receives depends on **the question the chapter is asking**, not on the chart alone. 強弱, 眾寡, 旺極, 剛柔, 實虛, 健, 權在一人, 從其強勢 are *different questions with different answers*, and the commentator selects among them by what he is trying to decide. V1 asked "what is this chart's strength?" as if that were a well-formed question with one answer. The source's own practice suggests it is not. |
| `READY_FOR_RULE?` | **NO** — and it should be resolved **before S2 selects axes**, because it bears on whether "the strength axis" is the right object to look for at all |

## OBS-13 — The same label licenses **opposite** remedies

| Field | Value |
|---|---|
| **Observation** | 形象's 任氏曰 splits the naive rule 旺則宜洩宜傷，衰則喜幫喜助 into four cases and insists the four words be used separately: 均是旺也，或洩之有害，而傷之有利；或洩之有利，而傷之有害 … 均是衰也，幫之則凶，而助之則吉；或幫之則吉，而助之則凶. Two worked charts demonstrate it: both are weak, and the correct treatments are opposites. |
| **Supporting cases** | `DTS-XINGXIANG-19` (財多身弱 → 幫之則有功) vs `DTS-XINGXIANG-20` (日主孤弱 → 助之則吉，幫之反害) · `DTS-XINGXIANG-17/18` for the 旺 half (傷之有功 vs 洩之有益，傷之有害) · `DTS-GANGROU-01/02` (both 旺之極矣, different remedies) |

| **Confidence** | **HIGH** — stated as doctrine *and* demonstrated on charts |

This is an argument against the V1 product design that is independent of whether the V1 doctrine was sourced. |
| `READY_FOR_RULE?` | **NO** — a constraint on what any future verdict may be used *for* |

## OBS-15 — 無根 is a **disqualification device for other parties**, not a Day-Master verdict (S1.5)

| Field | Value |
|---|---|
| **Observation** | Measured across all 131 records. 無根 occurs **18 times**. In **17 of 18** it is predicated of something *other than the Day Master* — an officer, a resource, a wealth star, or an element arriving in a luck period. Only **1** (`DTS-CONGXIANG-09`, 日主休囚無根) predicates it of the Day Master. The positive form 通根 shows the same skew: 14 clearly non-Day-Master vs 3 clearly Day-Master (5 ambiguous, mostly 通根身庫 constructions that do concern the Day Master). |
| **Measurement** | Programmatic scan of `ORIGINAL_JUDGMENT_TEXT`, resolving the element named immediately before each occurrence against the record's actual day stem. Reproducible; not an impression. |
| **The decisive collocation** | Three records pair rootlessness with an explicit instruction to **disregard** the element: 天干枯木無根，**置之不論** (`DTS-SHUNNI-02`) · 土金無根，**置之不用** (`DTS-SHANGGUAN-16`) · 丙火克絕，**置之不論** (`DTS-SHUNNI-03`). |
| **A second asymmetry** | 有根 appears **0 times** in the entire corpus. The source has no symmetric 有根/無根 pair. Its positive vocabulary is 通根 (20), 餘氣 (11), 得地 (6), plus qualified forms 庫根 · 微根 · 盤根 · 根深 · 根固 · 根重. |
| **Confidence** | **HIGH** — exhaustive count over the corpus, single lineage |
| **Why it matters, and this is a correction to how V1 read its own sources** | V1's R3 (有根 ⇒ 身強) and R4 (無根 ⇒ 身弱) were framed as a symmetric predicate pair applied to the Day Master. The corpus shows (a) one half of that pair, 有根, **is not a term this source uses at all**, and (b) the half it does use is, 94% of the time, **about a different party entirely**. V1 did not merely over-generalise a rule — it misidentified the grammatical subject of the construction. The source's operative question when it says 無根 is *"is this element a real player, or may I strike it from the reckoning?"* — a **functional-participation test on a party**, not a strength meter on the Day Master. |
| **How it fits OBS-11** | The two findings are the same shape seen from two sides. OBS-11: capacity is asserted of *a party, against a load*. OBS-15: rooting is assessed for *a party, to decide whether it counts*. Both point away from "the chart has a strength" and toward "the chart is a set of parties, each of which may or may not be able to act." |
| `READY_FOR_RULE?` | **NO** — single lineage, and cross-lineage testing is exactly what S1.5 exists for. But it is a hard constraint: any V2 rooting axis must carry **which party** it is about, or it will repeat V1's error. |

## OBS-17 — A complete rival doctrine exists with **no strength axis at all** (S1.5)

| Field | Value |
|---|---|
| **Observation** | 窮通寶鑑 (base text, 余春臺 recension, ~34,140 chars) organises its entire doctrine as *stem × month → needed element*. Deterministic substring counts over the full Wikisource text: **身強 0 · 扶抑 0 · 旺衰 0 · 得勢 0 · 黨眾 0 · 助寡 0**. Against: 寒 75 · 旺 87 · 暖 25 · 凍 22 · 燥 17 · 焚 6 · 濕 3. |

## OBS-22 — even 徐樂吾 (1936) does not use 專旺 as a 格 name — it is a taxonomic BUCKET (S1.6)

| Field | Value |
|---|---|
| **The refinement** | OBS-21 found 專旺 present as a named category in 徐樂吾. S1.6's cross-lineage bridge hunt re-examined the actual passage and found it is **not** a 格 name even there. |
| **The passage, ✓ MAIN-SESSION VERIFIED** by direct retrieval (`suanzhun.net/book/320.html`): 徐樂吾's 論用神 commentary organizes 取用之法 into a five-fold taxonomy: 「（一）扶抑。（二）病藥。（三）調候。（四）**專旺**。（五）通關。」 Under the **（四）專旺** heading itself, the worked example reads: 「春木成局，四柱無金，為**曲直仁壽格**，乃段執政祺瑞命造也。」 |
| **What this shows** | 專旺 is the label of a *method category* — one of five ways to select a 用神 — under which the actual pattern name, **曲直仁壽格**, still does the naming work. 徐樂吾 does not write 「此為專旺格」; he writes 「為曲直仁壽格」 and files it under a heading called 專旺. |
| **A second, independent finding narrows the pre-history further** | 神峰通考 (Ming, 張楠) contains 專旺 exactly twice, and both occurrences gloss a *different* concept — 《喜忌篇》's 「庚申時逢戊日，名食神干旺之方」, glossed as **專旺食神格**. One occurrence explicitly reports this as an inherited label, not 張楠's coinage: 「補曰：此段舊注謂**專旺食神格**，而或者又謂合神格，亦通。」 The referent is a 食神 in a specially-prosperous position — unrelated to the dominant-Day-Master-element sense V1 used. |
| **Provenance warning attached to the 徐樂吾 finding** | On the most common online edition (8bei8.com), this taxonomy is mislabelled `"原文2"` — presented as if it were 沈孝瞻's Qing base text. It is not: the collated 沈孝瞻-only witness (`donglishuzhai.net`, commentary-free) contains no such taxonomy, and the passage is immediately followed by worked charts of **twenty Republican-era politicians** (伍朝樞, 蔡孑民, 朱家驊, 段祺瑞, and others) — an 18th-century author did not chart 20th-century heads of state. **The 8bei8 原文/譯文 layer boundary is unreliable for this entire book** — a corroborating instance of the same hazard `OBS-19` documented for 沈孝瞻's own chapter. |
| **Confidence** | **HIGH** — direct main-session retrieval, cross-checked against a second author (張楠) using the same string |
| **Updated provenance statement** | The lexical precedent for 「專旺 + 格」 is Ming (神峰通考), and even there it is attributed to a 舊注 and glosses an unrelated concept. The transfer of the label to the *dominant-element* category is not attested in any of the five sources now checked (滴天髓, 淵海子平, 三命通會, 子平真詮 base, 徐樂吾). **Even the 1936 commentary that was the leading candidate for the coinage uses it only as a method-category bucket, with the classical 格 name (曲直仁壽格 etc.) still doing the actual naming.** The true 格-name coinage is later than every source examined so far, or lives in a corpus not yet searched (子平粹言 is the next candidate — see `BRIDGE_SEARCH_REGISTER.md` §2). |
| `READY_FOR_RULE?` | **NO** — sharpens OBS-21's prohibition rather than reversing it. If V2 uses 專旺 as a 格 name, it must be labelled `MODERN_SYSTEMATIZATION` and dated later than 1936, since even 1936 does not yet use it that way |

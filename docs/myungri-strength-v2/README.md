## Current gate: **S1.5 — SOURCE DIVERSIFICATION** — `PARTIAL_SOURCE_DIVERSITY_SHORTFALL`

S1.5 added four lineages (子平真詮, 淵海子平, 三命通會, 窮通寶鑑) plus the 徐樂吾 commentary layer.
**146 records · 15 non-滴天髓 · 6 source families.** Full accounting: [`S1_5_GATE_REPORT.md`](S1_5_GATE_REPORT.md).

Three results that **correct S1 conclusions**:

- **R11 is `SCHOOL_DEPENDENT`, not "REFUTED".** 淵海子平 states three times that a root voids a
  following pattern; 滴天髓 has six charts doing the opposite (`CF-011`). Every S1 "REFUTED" was
  one-lineage and did not say so — a scope warning now heads the counterexample register.
- **CF-009 is resolved as `TASK_RELATIVE_COMPATIBLE`,** not a contradiction. A chart has no single
  classification *vocabulary*; its structural situation is stable across vocabularies.
- **The "classical" strength doctrine is substantially 徐樂吾, 1936.** 扶抑 as baseline, 調候 as its
  supplement, the 得時/失時/黨眾/助寡 grid, and 專旺 as a pattern name are all **absent from every
  classical source measured** and present in the commentary layer (`OBS-18`, `OBS-19`, `OBS-21`).

`S2_PRE_FREEZE_READY = NO` — the blocker is that **zero charts are adjudicated by two lineages**, so
no cross-lineage disagreement can be settled on a chart.

⚠️ **Tooling warning for anyone repeating this work:** all four researchers independently found that
WebFetch's summarizing layer **fabricates matches** — returning plausible "containing sentences" that
do not contain the searched term. Every count that matters here was derived by deterministic string
matching over raw DOM text.

Build a professionally credible corpus of **real, source-provenanced worked natal cases** that a later
gate can use to discover structural axes. S1 collects evidence. **S1 does not decide doctrine.**

## The three rules that make this corpus worth having

1. **Never fabricate.** No invented chart, no invented quotation, no reconstructed missing pillar. A
   truthful 72-case corpus beats a fake 100-case one, and the gate report states the real number.
2. **Source judgment and our normalization are separate fields, always.** If 任鐵樵 writes 「財多身弱」,
   that string goes in the source field verbatim. Our reading goes in a different field. Merging them is
   how a corpus quietly becomes a record of our own opinions — and how V1's circularity started.
3. **Collect, don't conclude.** S1 produces no rules. A pattern seen in three cases is not a rule; it is
   three cases.

## What is deliberately NOT here

No strength classifier · no seven-band mapping · no special-pattern verdict · no Yongshin · no runtime
code of any kind. Those belong to gates S2–S6, and only if the evidence supports them.

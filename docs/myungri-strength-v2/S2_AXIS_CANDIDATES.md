## 0. The question this document had to answer first

Before listing axes: **is "strength" even the right object?**

Four of five lineages examined do **not** treat Day-Master strength as a
first-class question:

| Lineage | What it asks first | Strength's role |
|---|---|---|
| 滴天髓 | 氣勢 — the whole-chart flow | its own chapter, but framed as *treatment selection* |
| 子平真詮 (沈) | 月令 → 格局 → 用神 | precondition clause inside 格局 definitions; **傷用神甚於傷身** |
| 淵海子平 | which 象/格 does this admit to? | admission gate (類屬要身旺，從化要衰) |
| 三命通會 | 月令 + 十神 relations | already-known local fact; 通根 occurs 5× in 478k chars |
| 窮通寶鑑 | which season, which element | **absent entirely** — 身強/扶抑/旺衰/得勢 all measure 0 |

And the unifying doctrine that treats strength as primary is **dated and named**:
徐樂吾, 1936 — 故取用神，於扶抑之外，必須參合氣候，即調候之法也 (`OBS-18`, `OBS-19`).

That does not make strength unreal. 滴天髓 devotes a chapter to it and the term
appears 463 times in 三命通會. It means **strength is one view among several, not
the substrate they all reduce to.**

| | |

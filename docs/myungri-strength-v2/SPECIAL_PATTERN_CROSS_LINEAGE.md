| **專旺** | **ABSENT** | **ABSENT** | see §2 |

### The five mono-element forms

DTS treats them as instances of one idea (獨象) and spends its effort on what the
form *needs* (化神要昌). YHZP treats them as five separate 格, each with its own
entry test, its own 眉批 mnemonic verse, and its own example chart. **Same five
objects, incompatible organising principles.**

## 3. Entry conditions — the structural divide

### 曲直 (Wood)

**YHZP** (卷二 外十八格, verbatim):

> 此格以甲乙日取地支寅卯辰或亥卯未木局。**要不見庚辛之氣，見庚辛即官殺，非此格也。**
> 只從木而論，故曰曲直。運喜東方，北方有水，木賴水生，故從其類，主人多仁，忌西方運。

眉批: 甲乙生人寅卯辰，亥卯未全嫌白帝，但從木類正爲奇，得此清高仁且壽。
Chart: 李總兵 — 甲寅 丁卯 乙未 丙子

**DTS**: no 曲直 entry test. Its nearest material is 方局第十二, where two charts
of **the same composition** (木局全，混一寅字) receive **different** verdicts —
`DTS-FANGJU-03` is 從強, `DTS-FANGJU-04` is 非前造從強論也 — the stated difference
being whether a usable 食神 outlet exists.

**The divide, stated precisely:**

| | YHZP | DTS |
|---|---|---|
| Test shape | **binary glyph-presence** — one 庚 or 辛 voids the 格 | **functional** — does an outlet exist, does an element act |
| Gradient | none | throughout |
| Same composition → same verdict? | yes, by construction | **no** — AC-10 is a counterexample |

A single 庚 glyph voids YHZP's 曲直 regardless of whether that 庚 is rooted,
positioned adjacently, or already neutralised by 制 or 化. DTS weighs exactly
those things. These are not two phrasings of one rule.

## 4. Root policy — the sharpest conflict (`CF-011`)

| | YHZP | DTS |
|---|---|---|
| Root present in a following chart | **voids it** — 日主有根則不可棄，**主貧**。無根棄之則富 | **does not void it** — six charts |
| 比劫 present | **voids it** — 忌日主有根及比肩之地 | present in several confirmed cases |
| Stated form | binary switch, opposite outcomes | contextual, root's *function* assessed |
| Explicit refusals | — | 從兒不論身強弱，**非身弱論也** · 格取從官，**非身衰論也** |

YHZP states the root rule **three times independently** (棄命從財 眉批, 棄命從殺
忌-clause, 從象 或有根者不吉). It is not an aside.

DTS's six counter-cases are `DTS-CONGXIANG-01` (蟠根在未，餘氣在辰 → 其勢必從),
`DTS-CONGXIANG-08` (金逢祿旺 → 從金水), `DTS-JIACONG-03` (坐下辰土 → 非身衰論也),
`DTS-SHUNJU-03` (通根未戌 → 格成火土從兒), `DTS-SHUNJU-05` (逢祿比幫身 →
非身弱論也), `DTS-JIAHUA-03` (年之祿比 → 假化).

**This is a real doctrinal disagreement, not a terminology gap.** Recorded as
`CF-011`; R11 is reclassified `SCHOOL_DEPENDENT`.

**One asymmetry worth noting.** DTS *does* treat root **restoration by luck** as
destructive to an established pattern — `DTS-CONGXIANG-05`: 乙未運，衝破金局，
木得蟠根，**不祿**. So DTS is not indifferent to roots; it distinguishes *initial
presence* from *later restoration*, and the text does not explain why. YHZP draws
no such distinction. Neither position is currently derivable from the other.

## 5. Where strength sits in each system

**YHZP — strength is an admission gate, and the sequence is explicit.**

神趣八法 總釋 (verified verbatim):

> **類屬要身旺，而從化要衰也。**

眉批:

> 看八字**先明從化爲本，化不成方論財官，財官無取方論格局**

Sequence: **從化 → 財官 → 格局**. Strength is not a stage. It is the test that
decides *which branch of the 象 you are in* — 身旺 admits 類/屬, 衰 admits 從/化.

**DTS — degree is analysed in its own right**, in 衰旺第十八, whose 原注 frames it
as a treatment-selection question (旺則宜洩宜傷，衰則喜幫喜助), with the whole
apparatus of 太旺/旺極/太衰/衰極 and the 「似X」 reversal.

**Consequence for the §38 pipeline hypotheses** — recorded as `CF-012`:

| Hypothesis | YHZP | DTS |
|---|---|---|
| H1 ordinary strength → special pattern | contradicted | partially supported |
| H2 special screen → ordinary if ordinary | **explicitly supported** | not stated |
| H4 格局 first, strength secondary | partial — but 格局 is **last** here, not first | not stated |

**The single most important line in this file:** the two lineages use
**structurally different kinds of test** — YHZP's binary glyph-presence gates
versus DTS's functional weighing. A V2 special-pattern module cannot implement
"the classical rule" because there is no single classical rule. It must either
pick a lineage and disclose the choice, or model both and report which applies.

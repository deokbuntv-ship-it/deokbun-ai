# STRENGTH TERMINOLOGY REGISTER — S1.5

Status: **S1.5 RESEARCH ARTIFACT — NOT CANONICAL DOCTRINE**

## The rule this file exists to enforce

**NO ASSUMED SYNONYMY.** Two terms are treated as distinct until a source is
found that equates them. V1's failures began by silently identifying 旺 with 強,
無根 with 弱, and 從格 with 極弱 — none of which any consulted source asserts.

Every count below is **measured**, not estimated: deterministic substring matching
over full text. Where a count came from a summarizing model it is marked
`UNVERIFIED` and excluded from conclusions — three separate researchers reported
that layer fabricating matches, so no count from it is trusted.

## 3. Rooting — the asymmetry V1 missed

| Term | DTS | YHZP | Notes |
|---|---|---|---|
| **有根** | **0** | **present** | **DTS never uses it. YHZP does** — 日主**有根**則不可棄 |
| 無根 | 18 | present (dominant) | YHZP 卷四: the dominant operator in its 身弱論/棄命從殺論 verse |
| 通根 | 20 | not confirmed | DTS's positive form |
| 餘氣 | 11 | — | |
| 得地 | 6 | — | |
| 庫根 / 微根 / 盤根 / 根深 / 根固 / 根盤 / 得根 | 3/2/2/1/1/1/1 | — | DTS grades root *quality* |
| 根重 / 根輕 | 0 in cases | — | but present in DTS's 任氏曰: 長生祿旺，根之重者也；墓庫餘氣，根之輕者也 |

**Two findings here, and they point in the same direction:**

- **有根 = 0 in DTS.** V1's R3/R4 assumed a symmetric 有根/無根 pair applied to the
  Day Master. DTS uses no such pair — its positive form is 通根, and its qualified
  vocabulary (庫根, 微根, 盤根, 根深) grades quality rather than asserting presence.
- **無根 predicates the Day Master 1 time in 18** (`OBS-15`). 17 are about other
  parties; three pair with 置之不論 / 置之不用 — *strike it from the reckoning*.

**And YHZP does use 有根 — with the opposite operational meaning.** 日主有根則不可棄
makes root presence a **disqualifier for following**. So the one lineage that has
the term uses it to *block* a pattern, while the lineage without the term shows
six charts where a root does not block it (`CF-011`).

`ROOT_EQUALS_STRENGTH_SUPPORTED = NO` in any source examined.

## 9. What this register establishes

1. **There is no shared strength vocabulary across lineages.** DTS's 當令/通根/旺極
   apparatus, YHZP's 有根/身旺 gates, and QTBJ's 寒/暖/凍 vocabulary do not
   translate into one another.
2. **The terms V1 built on are frequently the wrong ones.** 得令 (0), 有根 (0),
   任財 (0), 身強 (0) — four load-bearing V1 predicates that the primary sources
   substantially do not use.
3. **One lineage has no strength axis at all** and reasons successfully without it.
4. **The unifying "standard doctrine" is datable.** 扶抑 as an organising baseline
   and 調候 as its supplement appear together in 徐樂吾, 1936.

**Carry-forward:** 子平真詮 and 三命通會 columns are pending. 子平真詮 matters most
— it is reported to use 得時/得地/得勢, which would be the first source to supply
the vocabulary V1 assumed was universal.
